# Perpatual website — GitHub Pages package

This folder is ready to upload to a GitHub repository and publish with GitHub Pages.

## Files
- `index.html` — complete website
- `assets/perpatual-brand-film.mp4` — web-optimized brand film
- `assets/perpatual-brand-film-poster.webp` — video poster image
- `.nojekyll` — prevents Jekyll processing

## Publish
1. Upload the contents of this folder to the root of your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing these files (usually `main`) and `/ (root)`.
5. Save.

## Language / video behavior
- English: the video plays with the original English voice-over.
- Any other language: the English voice-over is automatically muted while the video and on-screen text remain visible. The supporting copy around the video changes to the selected language.

The supplied master video was web-optimized so the media file remains below GitHub's normal 100 MB per-file limit.
